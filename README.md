# Агент для веб-чата DeepSeek

Chrome Manifest V3, обычные JavaScript ES-модули, HTML и CSS. Расширение добавляет к веб-чату инструменты браузера, файлов и Python и выполняет агентный цикл. Платного API, backend, npm, сборки и системного Python для пользователя нет.

## Установка и использование

1. Распакуйте ZIP в постоянную папку. В Chrome Windows/macOS откройте `chrome://extensions`, включите режим разработчика и загрузите папку с manifest.json.
2. Откройте DeepSeek и самостоятельно войдите. После установки или обновления расширения перезагрузите страницу DeepSeek.
3. На странице появятся только переключатель **Агент** и кнопка **Настройки**. Значок расширения также открывает настройки в отдельной вкладке.
4. В настройках выберите отдельную папку результатов и разрешите передачу данных задачи в веб-чат. Не выбирайте папку расширения или каталог с секретами.
5. Распознавание элементов автоматическое. Если интерфейс неоднозначен, используйте необязательный мастер «Привязать элементы кликами»: поле сообщения, отправка, текст готового ответа и его кнопка копирования. CAPTCHA и ошибки выбирать не нужно.
6. Настройки можно закрыть. Вернитесь в DeepSeek, включите «Агент», напишите задачу обычным полем и отправьте кнопкой или Enter. Shift+Enter оставляет перенос строки.
7. Расширение перехватит отправку, сохранит задачу, добавит инструкцию с инструментами, затем будет выполнять команды модели и отправлять результаты обратно в тот же чат. **Выключение переключателя останавливает цикл и Python.** При выключенном режиме обычная отправка DeepSeek сохраняется.

Сохранённые привязки используются как подсказки; при их устаревании применяются семантические признаки поля, кнопок и сообщений. Один распознаватель используется и перехватчиком отправки, и адаптером. При неоднозначности отправка блокируется. Завершение требует панели действий ответа, отсутствия признака генерации и стабильного текста. У иконок без доступного названия автоматическое распознавание может не сработать — тогда доступен мастер. Совместимость с текущим авторизованным DeepSeek и Titanium пока не проверена.

## Titanium и другие мобильные Chromium

Сайдбар не используется. Переключатель и настройки находятся на странице DeepSeek; кнопки рассчитаны на касания, есть мобильный viewport и экранная отмена мастера. Версия/сборка Titanium пользователя пока неизвестна, поэтому поддержка конкретных API не предполагается автоматически.

1. В настройках нажмите **«Хранить внутри браузера»**, если выбрать папку нельзя. Рабочие файлы сохраняются в OPFS. Доступ к обычной файловой системе телефона не требуется.
2. Привяжите элементы чата касаниями и разрешите передачу данных.
3. Нажмите **«Проверить возможности и показать файлы»**. Если CDP/debugger отсутствует или не работает, включите стандартные API страниц и нажмите **«Разрешить доступ к сайтам»**. Новое разрешение используется только для инструментов в выделенных рабочих вкладках.
4. Закройте настройки и выполняйте задачу в DeepSeek. Для скачивания результатов снова откройте настройки и нажмите проверку/список файлов, затем «Скачать» у нужного результата.

Совместимый режим использует chrome.scripting: чтение, snapshot, прокрутка, программные click/input. Он не требует CDP, но сайты могут не принимать программные события. Текстовые поля и побочные действия проверяются теми же правилами, ссылки на элементы инвалидируются после изменения DOM. Нужны tabs, scripting, storage.session, IndexedDB, Web Locks, Worker и WASM. Их отсутствие — реальное ограничение конкретного браузера, а не настройка селекторов.

Держите чат на экране во время выполнения. Перенос исполнителя в активную вкладку убирает зависимость от фоновой вкладки настроек, но не предотвращает выгрузку приложения Android, блокировку телефона или ограничения памяти. Pyodide с pandas/matplotlib может быть тяжёлым для телефона. Смена хранилища не переносит уже созданные файлы. Результаты внутреннего хранилища скачайте до удаления расширения или очистки данных браузера.

## Протокол и инструменты

«Системный промпт» здесь — обычное сообщение с инструкцией в веб-чате, а не настоящий API system-role. Расширение не может менять внутренние системные инструкции DeepSeek. В промпте нет сценариев контент-анализа или психологических рекомендаций.

Доступные модели инструменты: browser.open/snapshot/click/type/scroll/extract, files.list/read/write, python.run и task.finish. Модель возвращает один JSON:

```json
{"id":"step-1","tool":"browser.open","args":{"url":"https://example.com/"},"description":"Открыть источник"}
```

Результат содержит тот же id, статус и data либо структурированную ошибку. task.finish содержит итоговый ответ в summary. JSON-команды и результаты видны в обычной истории DeepSeek. Каждый ответ проходит валидацию до выполнения; завершённый id повторно не исполняется. Некорректный JSON получает до двух запросов исправления.

Старые corpus/analysis обработчики сохранены для совместимости с локальными тестами и ранее сохранёнными данными, но не включаются в описание инструментов новой задачи. Любой анализ пользователь задаёт собственным запросом; общие files и python подходят для CSV, отчётов и вычислений.

## Данные, разрешения и ограничения

В DeepSeek передаются задача, извлечённые тексты и результаты инструментов. Полные извлечения и вычисления сохраняются в выбранной папке, большие результаты передаются фрагментами с признаком truncated. Файлы чтения должны быть созданы задачей или явно названы пользователем. Для внешних действий браузера запрашивается подтверждение в чате через диалог Chrome.

Рабочие вкладки создаются отдельно от вкладки модели. Управление через chrome.debugger/CDP ограничено текущей задачей и сеансом браузера; специального debug-порта нет. После изменения DOM ссылки на элементы устаревают. Не меняйте разговор и не взаимодействуйте с рабочими вкладками во время цикла.

Сторонний текст не расширяет полномочия: проверяются аргументы, пути и принадлежность вкладок. Поддерживаются HTML-страницы; нет OCR, PDF, canvas и обхода iframe. URL ограничены HTTP(S) без credentials, query и hash. В MVP все click/type подтверждаются пользователем; чтение перечисленных в задаче URL, вычисления и новые файлы выполняются автоматически.

Новые результаты при конфликте получают новое имя. Только собственные неизменённые служебные результаты обновляются по сохранённому хешу. Пользовательские файлы не удаляются. Не редактируйте результаты параллельно записи: File System Access API не обеспечивает транзакции с внешними приложениями.

Лимиты: 5 рабочих вкладок, 50 шагов, 30 минут от создания задачи; CDP 20 секунд, ожидание модели 180 секунд, Python 60 секунд. Повторяющиеся команды без прогресса приводят к паузе. Результаты browser.extract ограничены 300000 символами, snapshot — 9000 символами/80 элементами. files.read возвращает до 12000 символов с offset. Усечение обозначается явно.

## Python

Локальный официальный Pyodide 0.27.7 / Python 3.12.7, NumPy 2.0.2, pandas 2.2.3, matplotlib 3.8.4 и зависимости уже находятся в vendor. Контрольные суммы wheels сверены с официальным lock-файлом. Во время работы зависимости не скачиваются.

Каждая команда получает code и JSON data, читает переменную data и присваивает JSON-совместимый result. Файлы из /results экспортируются в выбранную папку. Worker создаётся в sandbox с непрозрачным origin; он не получает Chrome API, IndexedDB расширения или directory handle. CSP запрещает внешнюю сеть; разрешены локальные ресурсы расширений. Нет mountNativeFS, процессов ОС и произвольных пакетов. Отмена завершает Worker. Ограничение памяти остаётся за браузером.

Пример Python: `result = {'sum': sum(data['values'])}`. stdout/stderr ограничены 50000 символами с флагами усечения; до 30 выходных файлов по 5 МБ каждый. Графики сохраняются через matplotlib Agg в PNG.

## Восстановление

Состояние и результаты хранятся в IndexedDB, а execution.jsonl, prompts.json и task-state.json экспортируются в выбранное хранилище. Service worker маршрутизирует короткие сообщения; цикл и Worker живут в скрытом iframe расширения внутри вкладки DeepSeek. Закрытие настроек не прерывает работу. Закрытие чата или его выгрузка системой прерывает цикл, но не удаляет сохранённые результаты. После этого откройте DeepSeek и раздел восстановления в настройках.

Неопределённая отправка не повторяется автоматически. Проверьте исходный чат: примите новый завершённый ответ либо сбросьте отправку только после уверенной проверки, что она не произошла. Незавершённую команду сверяйте по вкладке/файлам и запишите фактический результат. Не начинайте новую задачу с неразрешённым неопределённым действием. После перезапуска браузера старые вкладки не считаются управляемыми: агент должен открыть новые. При отзыве разрешения нажмите «Восстановить доступ».

Для продолжения восстановленной задачи используется соответствующая кнопка в настройках. Не удаляйте расширение ради обновления: это может уничтожить IndexedDB. После правок исходников достаточно «Обновить» в chrome://extensions и переоткрыть настройки/страницу DeepSeek. Никакой сборки нет.

## Проверки и известные границы

`tests/index.html` запускает локальные проверки без npm и сервера. Тестовые данные находятся в отдельной IndexedDB и OPFS, пользовательская папка не затрагивается. Также в разработческом Chromium проверены перехват настоящего клика и Enter, обычная отправка при выключенном режиме, выключение агента, мастер четырёх кликов и пропуск программной отправки адаптера.

В этой среде администратор запрещает загрузку unpacked-расширений. Проверки выполнялись через HTTP-стенд и настоящий CDP с заменённым транспортом Chrome API. Контур content script → service worker → исполнитель в iframe → Python проверен с подменённым транспортом Chrome API. Текущий авторизованный DeepSeek, extension-origin iframe в установленном расширении, реальный выбор пользовательской папки и устройства Windows/macOS/Titanium требуют ручной приёмки. Бесплатный чат может менять интерфейс и вводить ограничения. Токены не извлекаются, внутренние API не используются, CAPTCHA не обходится.

Архитектура: chat-ui.js — переключатель, перехват и мастер; workspace.js — настройки и скачивание результатов; service-worker.js — проверка отправителей и маршрутизация; executor.js — выполнение в iframe чата; DeepSeekAdapter — DOM чата; AgentController — цикл; BrowserTools — CDP; ProjectFiles — папка; PythonRuntime — sandbox Worker; StateStore — состояние. Подробности предыдущих проверок — VALIDATION.md.

## GitHub Actions

В корне репозитория должны находиться manifest.json, .github и vendor. Workflow проверяет синтаксис JS, manifest и контрольные суммы, затем упаковывает существующие файлы. На push/PR доступен Artifact с ZIP и SHA-256, срок хранения 30 дней. Push тега v* публикует предварительный Release; право contents:write получает только job публикации. Python на GitHub runner нужен лишь упаковщику, пользователю устанавливать его не требуется.
