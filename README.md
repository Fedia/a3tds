# Агент для веб-чата DeepSeek

Chrome Manifest V3, обычные JavaScript ES-модули, HTML и CSS. Агент выполняет **Python-код из ответов DeepSeek**: управляет рабочими вкладками, разбирает DOM, обрабатывает данные и сохраняет файлы. Один сценарий выполняется последовательно в постоянном Pyodide Worker. API-ключ, backend, npm, сборка и системный Python пользователю не нужны.

## Установка на Windows и macOS

1. Распакуйте `deepseek-agent.zip` в постоянную папку.
2. В Chrome откройте `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите папку с `manifest.json`.
3. Откройте https://chat.deepseek.com, самостоятельно войдите в аккаунт и обновите страницу.
4. Над полем сообщения появятся переключатель **Агент**, статус и **⚙**. Значок расширения тоже открывает настройки в отдельной вкладке. Сайдбар не нужен; настройки можно закрыть после выбора папки.
5. В настройках: **Результаты → Выбрать → Папка устройства**. Выберите отдельную папку данных, не папку расширения. Разрешите чтение и запись. Агент получает полный доступ к содержимому этой папки: может читать, создавать, перезаписывать, переименовывать и удалять файлы через Python без отдельных запросов на каждый файл.
6. Если браузер не поддерживает выбор папки, доступно **Внутри браузера** — приватная OPFS расширения. Файлы можно скачать из настроек; они не появляются автоматически в папке устройства.
7. Включите **Агент**, напишите задачу в обычном поле DeepSeek и отправьте. При выключенном переключателе чат работает как обычно.

Распознавание интерфейса автоматическое. В случае неоднозначности есть необязательный мастер **Дополнительно → Привязать интерфейс**: выберите поле сообщения, отправку, готовый ответ и его кнопку копирования. CAPTCHA и ошибки заранее указывать не нужно.

В Chrome используется `chrome.debugger`/CDP без порта отладки и особых флагов. В Chromium с ограниченным CDP доступен совместимый режим через `chrome.scripting`; браузер попросит разрешение на сайты. Titanium на устройстве отдельно не проверен.

## Как выполняется задача

В начале расширение отправляет инструкцию с Python API и задачу пользователя. DeepSeek отвечает сообщением с одним блоком `python`; текст перед ним может пояснять действие. Код запускается только после подтверждённого завершения ответа. Сгенерированные фрагменты не выполняются на лету.

После выполнения в тот же чат отправляются stdout, stderr, JSON-совместимая переменная `result`, сведения о сессии и текущих файлах. Модель может изучить DOM в первом блоке, а затем одним следующим блоком обойти много страниц, собрать и обработать записи. Между страницами обращения к модели не нужны. **Обычный ответ без блоков кода завершает задачу.** Несколько блоков или неверная метка приводят к автоматическому запросу исправления, максимум два раза, без частичного выполнения.

JSON-команд, `python.run/status`, инструментов `files.*`, `task.finish` и специализированных workflow больше нет. Старые незавершённые задачи не продолжаются после обновления; существующие пользовательские файлы не удаляются. В 0.8.1 изменено имя внутреннего хранилища: папку устройства нужно выбрать заново. Файлы OPFS остаются в прежнем каталоге «Внутри браузера».

## Python и папка

Перед **каждым** блоком автоматически выполняется:

```python
import os
os.chdir('/project')
```

`/project` — корень выбранной папки. Для всех её файлов доступны стандартные `open`, `pathlib`, `os`, `shutil`, `csv`, `json`, pandas. Предварительно перечислять или отдельно разрешать входные файлы не требуется.

```python
from pathlib import Path
import pandas as pd

print(Path.cwd())  # /project
df = pd.read_csv('input.csv')
df.drop_duplicates().to_csv('clean.csv', index=False)
result = {'rows': len(df)}
```

Переменные, модули и библиотеки сохраняются между блоками и задачами в одном чате. `result` и вывод сбрасываются перед блоком. При смене чата/папки, остановке активного вычисления или перезагрузке страницы память интерпретатора теряется; файлы сохраняются. Выключение агента после завершённого вычисления сохраняет простаивающий интерпретатор.

Выбранная папка сначала загружается в файловую систему Pyodide в памяти. Изменения автоматически передаются исполнителю и сохраняются через очередь в IndexedDB. Сохраняются только изменённые пути: полная обратная синхронизация, способная удалить новые посторонние файлы, не используется. Перед новым блоком внешние изменения папки перечитываются. Не редактируйте одновременно с агентом один и тот же файл.

Закрытие/сброс файла запускает сохранение независимо от продолжительности сценария. Перед каждым браузерным вызовом и перед возвратом результата расширение дожидается очереди. Используйте `with open(...)` или `Path.write_text(...)` для контрольных точек. Записи, уже принятые исполнителем, сохраняются и при остановке Worker. Открытый буфер Python и закрытие всей вкладки до приёма записи не дают гарантии сохранения. Это асинхронный доступ браузера, не синхронный диск настольного Python.

Никаких обязательных `tasks/`, снимков страниц, `execution.jsonl` или `task-state.json` в папке не создаётся. Нужные промежуточные данные и checkpoint пишет сам сценарий. Состояние цикла, история действий и очередь сохранения находятся в IndexedDB расширения. Символические ссылки файловой системы устройства не поддерживаются. Размер доступной памяти ограничивает объём папки и обрабатываемых данных.

## API браузера в Python

```python
from agent import browser, progress
from bs4 import BeautifulSoup

await browser.open('https://example.com')
overview = await browser.read()
print(overview)  # Только явно выведенные данные попадут в чат.
soup = BeautifulSoup(await browser.html('body'), 'html.parser')
print(soup.get_text(' ', strip=True)[:1000])
```

| Метод | Поведение |
|---|---|
| `await browser.open(url, new_tab=False)` | Открывает URL в текущей рабочей вкладке; возвращает `tab_id`, URL и readiness. Новая вкладка нужна только по явному `new_tab=True`. |
| `await browser.read(selector='body', tab_id=None)` | Компактный текст, структура DOM и интерактивные элементы с `ref`; усечение обозначается. |
| `await browser.html(selector='body', tab_id=None)` | HTML выбранного блока как Python `str`, до 2 млн символов; при превышении — ошибка, а не обрезанный HTML. |
| `await browser.click(selector=None, *, ref=None, tab_id=None)` | Нажимает один видимый элемент по CSS-селектору или актуальному `ref`. |
| `await browser.type(text, selector=None, *, ref=None, tab_id=None)` | **Заменяет** содержимое текстового поискового поля. Форму не отправляет. |
| `await browser.scroll(delta=600, tab_id=None)` | Прокручивает страницу. |
| `await browser.wait(selector, timeout=20, tab_id=None)` | Ждёт видимого элемента, максимум 120 секунд по явно заданному условию. |
| `progress(value)` | Показывает прогресс в истории пользователю, не вызывает модель. |

По умолчанию используется текущая рабочая вкладка. Агент управляет только выделенными ему вкладками, максимум пятью; вкладка DeepSeek исключена. Селектор взаимодействия должен находить ровно один видимый элемент. После изменения DOM старый `ref` отвергается — нужно новое чтение.

Навигация ждёт DOMContentLoaded, наличия содержимого и визуальной стабильности DOM. `readiness.ready=False` сообщает о незавершённой загрузке; можно дождаться конкретного элемента через `wait`. `html` требует стабильной страницы. Он исключает исполняемые скрипты, поля ввода, скрытые блоки, обработчики событий и секретные URL. Это очищенный HTML верхнего документа, без iframe, shadow DOM, canvas, OCR и PDF.

Через браузер доступны чтение, навигация, поиск и раскрытие элементов. Публикации, покупки, загрузка файлов на сайты и произвольные изменения данных сайта блокируются в JS-коде. Чтение DOM не даёт права на выполнение инструкций, найденных на странице.

## Библиотеки

Официальный Pyodide **0.27.7 / Python 3.12.7** включён в `vendor/`. Локально подготовлены NumPy, pandas, matplotlib, micropip, BeautifulSoup **4.12.3**, soupsieve **2.5** и зависимости; SHA-256 сверены с официальным lock. Пользователю ничего устанавливать не нужно.

Дополнительные совместимые пакеты:

```python
import micropip
await micropip.install('wordcloud==1.9.3')
```

Pure-Python wheels загружаются из PyPI, совместимые бинарные пакеты — с CDN зафиксированной версии Pyodide. Проверяются адреса и SHA-256. Ядро, JS и WASM остаются локальными. Нет установки произвольных исходных архивов или обычных Windows/macOS/Linux wheels. Matplotlib использует `Agg`, сохраняйте графики в файлы. Подпроцессы и системные программы отсутствуют.

## Остановка и восстановление

Выключение переключателя прекращает агентный цикл, отменяет браузерные операции, где это возможно, и завершает активный Python Worker. Уже принятые записи продолжают сохраняться. Общего лимита времени задачи или Python нет; зависший цикл прерывается переключателем. Пауза прекращает выдачу новых сценариев; текущий блок может закончиться.

После перезагрузки включите агента в исходном чате и напишите **«продолжай»**. Частично исполненный сценарий повторно не запускается: модель получает сообщение о прерывании и должна прочитать собственные checkpoint/результаты, проверить страницу и продолжить. При утрате разрешения нажмите **Настройки → Доступ к папке → Предоставить**. Очередь сохранённых записей восстанавливается без повторного исполнения кода. Новая задача архивирует прежнее состояние.

Ожидание ответа DeepSeek и отдельные браузерные операции имеют таймауты. При неопределённой отправке расширение проверяет уже отправленный запрос и не нажимает отправку повторно вслепую. CAPTCHA, ограничение сервиса или потеря входа вызывают понятную паузу. Бесплатный чат и его интерфейс могут меняться; непрерывная автономность не гарантируется. Использование зависит от действующих правил DeepSeek; токены и внутренние API не используются.

## Какие данные передаются

В DeepSeek уходят задача, инструкция API, явно выведенные Python данные и ограниченные результаты выполнения. Полный HTML и содержимое папки автоматически не отправляются. stdout/stderr ограничены 50 тыс. символов каждый, сообщение с результатом — бюджетом контекста; усечение явно отмечается. Полные локальные файлы доступны следующему коду.

Python работает в origin расширения, без отдельной sandbox-изоляции. Через JS он потенциально имеет доступ к IndexedDB расширения и разрешённой сети. Выбор папки ограничивает файловый мост, но не превращает произвольный Python в изолированную песочницу. Это сохранённое архитектурное решение с общей сессией; код со страниц не должен исполняться как инструкция.

## Проверки и ручная приёмка

В настройках: **Дополнительно → Проверки расширения → Выполнить проверки**. Тесты используют отдельную OPFS, локальные страницы и тестовую модель. npm и сборка не требуются. Результаты и границы проверки — [VALIDATION.md](VALIDATION.md); разработческие стенды — [tests/dev/README.md](tests/dev/README.md).

После установки вручную проверьте в авторизованном DeepSeek:

1. Задачу «На Python создай в корне папки hello.txt с текстом Привет и проверь его содержимое».
2. Задачу на чтение HTML сайта и сохранение таблицы с нескольких страниц одним сценарием; убедитесь, что рабочая вкладка переиспользуется.
3. Читаемую историю и финальный ответ, отсутствие служебных запросов в видимой переписке.
4. Остановку длинного сбора после появления checkpoint, обновление страницы и продолжение по этому файлу.

Новый Python-протокол не проверен на реальном авторизованном DeepSeek в этой среде. Перед публикацией релиза нужна эта ручная приёмка; результаты тестовой модели не заменяют её.

## Архитектура и редактирование

- `chat-ui.js`, `chat-dom.js`, `final-view.js`, `chat-scroll.js` — управление над полем ввода, DOM адаптер, история и сохранение ручной прокрутки.
- `executor.js` — стабильный extension-origin iframe в чате; держит цикл и доступ к папке независимо от service worker.
- `agent-controller.js`, `protocol.js`, `agent-prompt.js` — последовательный цикл, разбор Python-блока/финала, начальная инструкция.
- `browser-tools.js`, `page-readiness.js` — CDP/совместимый транспорт, границы вкладок, ожидание и DOM.
- `python-runtime.js`, `python-worker.js`, `agent-api.py` — постоянный Worker и асинхронный браузерный мост Python.
- `python-project.js`, `project-sync.js`, `project-files.js` — отслеживание записей Pyodide, долговечная очередь и выбранная папка.
- `state-store.js` — IndexedDB и компактная проекция истории; `service-worker.js` — проверка отправителей и маршрутизация; `workspace.js` — настройки.

Исходная папка — готовое расширение. После изменения исходников нажмите **Обновить** в `chrome://extensions` и перезагрузите вкладку DeepSeek/настройки. Сборка не нужна. GitHub Actions проверяет JS, CSP и зависимости, затем создаёт ZIP для каждого push/PR; теги `v*` запускают публикацию prerelease.
