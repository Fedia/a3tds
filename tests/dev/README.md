# Необязательные разработческие проверки

Для использования расширения эти зависимости не нужны. Обычные тесты доступны в tests/index.html внутри расширения.

Эти два стенда воспроизводят проверки, выполненные в среде, где запрещена установка unpacked-расширений. Требуются Python 3, пакет playwright и Chromium. Можно указать путь к браузеру через CHROMIUM_BIN; иначе используется системный chromium или установленный Playwright браузер.

- `python tests/dev/mobile-engine.py` — touch viewport, код service worker/исполнителя, закрытие настроек, настоящий Python Worker, OPFS, скачивание и остановка.
- `python tests/dev/touch-ui.py` — касания, перехват отправки, обычный чат, мастер четырёх касаний и экранная отмена.

HTTP-серверы слушают только 127.0.0.1. Chrome API эмулируются мостом Playwright. Это не подмена проверки extension-origin: для неё нужна разрешённая установка расширения в реальном Chrome/Titanium. Временный скачанный JSON имеет имя psy-agent-mobile-test-result.json в системном каталоге временных файлов и содержит только тестовую сумму.
