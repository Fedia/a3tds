# Необязательные разработческие проверки

Для использования расширения эти зависимости не нужны. Обычные тесты доступны в tests/index.html внутри расширения.

Эти стенды воспроизводят проверки, выполненные в среде, где запрещена установка unpacked-расширений. Требуются Python 3, пакет playwright и Chromium. Можно указать путь к браузеру через CHROMIUM_BIN; иначе используется системный chromium или установленный Playwright браузер.

- `python tests/dev/python-session.py` — настоящий постоянный Worker/Pyodide под CSP manifest: тёплый запуск без загрузок, общие переменные/файлы, исключения, сброс, смена чата/папки и замеры этапов.
- `python tests/dev/python-startup.py` — отсутствие ответа Worker, отказ конструктора/WASM, задержка загрузки, выборочная загрузка пакетов, отсутствие instantiateStreaming, неверный MIME и отмена. Сроки задаются только явно для диагностики.
- `python tests/dev/python-packages.py` — настоящие пакеты PyPI/CDN, транзитивные зависимости, wordcloud/PNG и переиспользование. HTTPS проходит через настроенный proxy и TLS-verified urllib; проверка сертификатов не отключается.
- `python tests/dev/short-protocol.py` — сопоставление коротких команд с подтверждениями, восстановление Markdown-блоков и перестроение списка сообщений на искусственном DOM.
- `python tests/dev/mobile-engine.py` — touch viewport, код service worker/исполнителя, закрытие настроек, настоящий Python Worker, OPFS, скачивание и остановка.
- `python tests/dev/ui-layout.py` — компактные настройки, светлая/тёмная темы, встроенная панель чата, единственная строка паузы и автоматический scripting fallback. Скриншоты сохраняются в системную временную папку psy-agent-ui-preview; путь можно задать через UI_PREVIEW_DIR.
- `python tests/dev/chat-scroll.py` — сворачивание высоты принятых служебных сообщений, обновление истории без пересоздания узлов, сохранение позиции при попытках автопрокрутки, настоящие wheel/touch события Chromium и возврат к последнему сообщению. Страница и автопрокрутка тестовые; это не живая проверка DeepSeek.
- `python tests/dev/final-view.py [путь-к-экспорту.html]` — история действий и финал только из состояния контроллера, скрытие служебных сообщений, сохранность исходного ответа и его геометрии, безопасный вывод текста. По умолчанию используется обезличенная фикстура.
- `python tests/dev/touch-ui.py` — касания, перехват отправки, обычный чат, мастер четырёх касаний и экранная отмена.

HTTP-серверы слушают только 127.0.0.1. Chrome API эмулируются мостом Playwright. Это не подмена проверки extension-origin: для неё нужна разрешённая установка расширения в реальном Chrome/Titanium. Временный скачанный JSON имеет имя psy-agent-mobile-test-result.json в системном каталоге временных файлов и содержит только тестовую сумму.

`python .github/scripts/test_manifest.py` проверяет приватность Python-ресурсов, отсутствие sandbox и ограничения CSP без Playwright; упаковщик выполняет ту же проверку автоматически. Это проверка manifest, а не установленного расширения.
