# Изменения

## 0.8.1

- Унифицированы нейтральные названия приложения, внутренних идентификаторов, хранилища, UI и архива `deepseek-agent.zip`.
- Тестовые тексты заменены универсальными примерами о таблицах и обновлениях программ.
- Обновлены упаковка и GitHub Actions; официальные зависимости сохранены без изменений.

## 0.8.0

- Один последовательный Python-сценарий из обычного блока ответа DeepSeek вместо JSON-команд. Финальный ответ — обычный текст.
- `from agent import browser` управляет вкладками и получает DOM; BeautifulSoup 4.12.3 и soupsieve 2.5 включены локально.
- Полный stdlib доступ к выбранной папке, `os.chdir('/project')` перед каждым блоком. Создание, перезапись, переименование и удаление файлов в корне и подпапках.
- Долговечная очередь изменённых файлов, барьеры перед браузерными действиями, сохранение checkpoint при остановке.
- Удалены фоновые Python jobs, files-тулы, обязательные tasks/снимки страниц и специализированные workflow.
- Прерванные сценарии не повторяются автоматически: модель продолжает по собственным файлам.
- Протокол проверен на фикстурах и настоящем Pyodide. Живая приёмка авторизованного DeepSeek остаётся отдельным шагом.
